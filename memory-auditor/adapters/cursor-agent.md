# Memory Audit Adapter — Cursor

> This file is regenerated by `memory-audit.ps1` after each audit run. Do not edit manually.

## How to use this adapter in Cursor

Open Cursor's AI chat and paste:

```
Read the file memory-auditor/adapters/cursor-agent.md and the audit report it references.
Process the proposed changes following the authorization protocol described there.
```

Or trigger the audit directly from Cursor's terminal:

```powershell
.\memory-auditor\scripts\memory-audit.ps1
```

Then tell Cursor's agent to process the generated report.

## Authorization protocol

| Action | Risk | Required |
|--------|------|----------|
| Mark as `dudosa` | Low | Automatic |
| Mark as `obsoleta` | Medium | Confirm before applying |
| Delete file | High | Always confirm — show impact |
| Resolve contradiction | Medium | Confirm after showing resolution |

## Soft-delete protocol

1. Update `estado: obsoleta` in frontmatter
2. Set `motivo_cambio` with reason
3. Update `fecha_actualizacion` to today's date
4. Propose file deletion as a separate, explicit action

## Instruction template (populated after first audit)

```
Audit report: memory/audits/audit-YYYY-MM-DD.md

For each Obsoleta entry → present as HIGH risk, confirm before changing
For each Dudosa entry → present review options, MEDIUM risk
For each Contradiction → show both entries + proposed winner, MEDIUM risk

Apply authority hierarchy: code > tests > docs > SQLite-RAG > Engram > chat
```
