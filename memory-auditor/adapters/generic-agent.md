# Memory Audit Adapter — Generic (any AI)

> This file is regenerated by `memory-audit.ps1` after each audit run. Do not edit manually.
> Use this adapter when no specific environment (Claude Code, Cursor, Codex) is detected.

## Self-contained prompt

Copy and paste the following into any AI chat (ChatGPT, Claude.ai, Gemini, etc.),
replacing `[REPORT CONTENT]` with the contents of the latest audit report:

---

```
You are a memory auditor assistant. I will give you an audit report from the toolMemoMati
framework. Your job is to help me clean up stale and contradicted memory entries.

IMPORTANT RULES:
- Never delete or modify anything without my explicit approval
- For HIGH-risk actions (deleting entries), always describe the full impact first
- For MEDIUM-risk actions (marking obsoleta, resolving contradictions), show your proposal and wait
- Use this authority hierarchy to resolve conflicts:
  current code > passing tests > active documentation > SQLite-RAG > Engram > chat context

For each item in the report:
1. Summarize what the issue is in plain language
2. Tell me what action you propose and why
3. Ask: [A]pprove / [R]eject / [M]odify?
4. Only proceed after I respond

Here is the audit report:

[REPORT CONTENT]
```

---

## How to get the report content

```powershell
# Run the audit
.\memory-auditor\scripts\memory-audit.ps1

# The report is at:
memory/audits/audit-YYYY-MM-DD.md
```

## Soft-delete protocol (instruct the AI to follow this)

Memory files are never deleted directly:
1. Change `estado:` to `obsoleta` in the frontmatter
2. Add `motivo_cambio:` explaining why
3. Update `fecha_actualizacion:` to today's date (YYYY-MM-DD)
4. Ask the user separately whether to physically delete the file
