# Memory Audit Adapter — GitHub Copilot / Codex

> This file is regenerated by `memory-audit.ps1` after each audit run. Do not edit manually.

## How to use this adapter with Copilot / Codex

In GitHub Copilot Chat or a Codex-powered environment, paste:

```
Read the file memory-auditor/adapters/codex-agent.md.
Then read the audit report it references.
Process the proposed changes — always ask before any destructive action.
```

Or run the standalone audit script and process the report manually:

```powershell
.\memory-auditor\scripts\memory-audit.ps1 -NoAdapters
# Then open the generated report in memory/audits/
```

## Authorization protocol

| Action | Risk | Required |
|--------|------|----------|
| Mark as `dudosa` | Low | Automatic |
| Mark as `obsoleta` | Medium | Ask before applying |
| Delete file | High | Always ask — list what will be lost |
| Resolve contradiction | Medium | Ask after showing resolution |

## Soft-delete protocol

Never delete memory files directly:
1. Open the file and change `estado:` to `obsoleta`
2. Add `motivo_cambio:` with the reason
3. Update `fecha_actualizacion:` to today
4. Suggest file deletion as a follow-up action requiring explicit approval
